Error 404 Tech Rescue Agency
A website developed for a device repair company for the COM109 Client-Side Development module at Ulster University.
Project Summary
Error 404 Tech Rescue Agency is a responsive and interactive five-page website for a hypothetical repair business where the visitor will be able to browse for repair services offered, calculate the cost of repair, request a repair service through an online form, and monitor tickets via a reference code.
The project demonstrates the usage of semantic HTML, CSS, JavaScript, jQuery, event listeners, form validation, accessibility functionalities, and client-side database storage.

Features
•	Theme Toggle: Switch between dark/light themes, with preference stored
In localStorage
•	Service Catalog: List of services and dynamic price estimator for the selected
repairs.
•	Booking Form: A form to book a repair with client-side validation of
contact details, device details, and complaint.
•	Ticket Generation: The repair reference in format ERR-#### is issued on
successful booking.
•	Ticket Tracking: Information about the repair and the (simulated)
progress of the repair is shown based on the ticket reference.
•	Data Transparency: The information saved in the local browser can be
viewed and deleted from the data viewer page.
•	Responsive Navigation: The interactive menu that works on different screen
sizes
•	Responsive Design: The mobile-first design of all the web pages
•	Accessibility: Semantic HTML, ARIA roles, validation, and accessible UI.

Technology Stack
•	HTML5 - Semantic markup, page structure, and form elements.
•	CSS3 - Styling, responsive layouts, CSS custom properties, themes, transitions, and visual presentation.
•	JavaScript - Event handling, form validation, calculations, Local Storage handling, and DOM manipulation.
•	jQuery 3.7.1 - DOM interaction, event handling, and interactive functionality.
•	localStorage API - Client-side storage of user preferences and repair ticket information.

Project Constraints
The project uses only localStorage as the means of storing data as it does not utilize any server or database.
It handles all aspects of data storage, validation, ticket creation, status, and updates, entirely on the client-side.
This allows the website to operate as it does while being run entirely from the user’s web-browser.
