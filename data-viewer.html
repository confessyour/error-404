Behind the scenes

Where this app's data actually lives.

This app doesn't have a server or a database — everything it saves is written to your browser's Local Storage, a small key/value store built into the browser itself.

What am I actually looking at?

Every ticket you submit on Book Repair gets written to localStorage under this site's origin. It isn't a file you can open in Notepad or File Explorer — it lives inside the browser, tied to this device and this browser only. The panels below read that storage directly and print it here, and you can also see the raw entries yourself in DevTools → Application tab → Local Storage (Chrome/Edge) or DevTools → Storage tab (Firefox).
